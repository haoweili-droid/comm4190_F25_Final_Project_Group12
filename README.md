# comm4190_F25_Final_Project_Group12

KidTalk Mirror: LLM Workflow, Prompting, and Testing

This repository contains all milestones and supporting materials for Group 12’s final project in COMM 4190 (Fall 2025). Our application, KidTalk Mirror, is an LLM-powered reflective tool designed to help parents better understand and improve everyday communication with their children through audio-based interaction analysis, language feedback, and growth tracking.

The repository is organized by milestone to clearly document the evolution of the idea, prompting strategy, workflow design, and testing of our LLM application.

## Project Overview

App Concept: KidTalk Mirror
Core Goal: Help parents reflect on parent–child interactions by analyzing short audio clips, identifying communication patterns (e.g., pressure, emotional attunement), and offering gentle, actionable language alternatives and growth insights.

Key Capabilities:
- Audio-based interaction analysis
- LLM-driven pattern tagging and explanation
- Language “swap” suggestions grounded in developmental communication principles
- Longitudinal growth dashboard
- Skill-building content linked to detected patterns
